\begin{frame}{Step 1: Generating the watermark}
    The first step is to generate the watermark sequence. This is done by using the key as a seed for the random number generator. In this case we use a simple \textbf{mersenne twister} generator.

    The result is a fixed sequence $\xi \sim \text{Uniform}[0, 1]^{|\mathcal{V}|}$ where $\mathcal{V}$ is the vocabulary of the model. The watermark sequence is then generated by sampling from the model's output distribution using the watermark sequence as a seed.
